Bring the new register up, prove it, then let it take over

This is the on-site sequence for wiring one physical terminal to Elite POS and cutting it over from swiftPOS. Every checkbox here persists in this browser, so you can walk away mid-install and pick back up. Nothing in Prep → Acceptance touches swiftPOS's ability to sell — that only happens at the scheduled Cutover step, on purpose.

ELITE_POS_QZ_CERT_PATH = C:\ProgramData\ElitePOS\qz\digital-certificate.txt
ELITE_POS_QZ_KEY_PATH = C:\ProgramData\ElitePOS\qz\private-key.pem
ELITE_POS_PRINTER_ALLOWLIST = <exact queue name from above>
ELITE_POS_ALLOWED_ORIGINS = <production Elite admin origin>
ELITE_POS_SIGNER_PORT = 8182
Verify: curl http://127.0.0.1:8182/health must return ok — from this machine only.
